# Playstead

Playstead is a self-hostable platform for playing small social games together. Platform
services own identity, live rooms, leaderboards, global chat, and private group chats.
Games plug into those services through explicit server and frontend modules.

The first game is **Atlas Drop**, a daily and live geography challenge. Players receive five
location prompts and place each one on a globe. The server scores geographic accuracy and
reveals the answer after every guess.

## Product language

- **Playstead**: the platform and self-hosted instance.
- **Atlas Drop**: the geography game.
- **Daily expedition**: the shared five-round puzzle for one calendar day.
- **Live table**: a synchronous multiplayer Atlas Drop room.
- **Circle**: a private group chat created by a player and joined with an invite code.
- **Commons**: the instance-wide global chat.
